# Irmia Agent `v@@VERSION@@` · Windows x64 内测包（便携版）

这是**内测版**：功能面到"能装能用"为止，但接口、配置字段与数据结构都还会有破坏性改动。
包是**便携**形态——不解压到系统目录、不写注册表、不建开始菜单项，删掉文件夹就等于卸载。

---

## 一、30 秒开始

1. 把**整个文件夹**解压到你自己的一个空目录里（例如 `D:\IrmiaAgent`）。
   ⚠️ 别在压缩包里直接双击，也别只解压 `START.cmd` 一个文件——它要跟同目录的其它文件配合。
2. 双击 **`START.cmd`**。
3. 黑色窗口会依次打印这几步，看到绿色那一行就是起来了：

   ```
   [hh:mm:ss] 正在启动后端（自带 Node 运行时）…
   [hh:mm:ss] 后端已就绪
   [hh:mm:ss] 正在打开界面…
     界面已开。本地服务：http://127.0.0.1:7788（框架不提供网页界面，界面就是那个窗口）
   ```
4. 界面窗口会自动打开。**第一次打开它会让你设一个密码**——设完就是登录态，以后用它进。
   想改密码或登出：界面里 `设置` → `账号与安全`。
   忘记密码：关掉程序，删掉 `data\.auth.json`，重新双击 `START.cmd` 再设一次。

## 二、不需要装任何东西

| 你可能会担心 | 实际情况 |
| --- | --- |
| 要不要装 Node？ | **不用**。包里自带 Node `v22.19.0`（`runtime\node\`，附 LICENSE）。启动器只认包里这一份，PATH 里有没有 node 都不影响。 |
| 要不要装 Flutter / Visual Studio？ | **不用**。界面是编译好的 release 产物（`gui\`）。 |
| 要不要装 VC++ 运行库？ | **不用**。`msvcp140 / vcruntime140 / vcruntime140_1` 三个 DLL 与界面放在同一目录（Microsoft 允许随应用分发）。 |
| 要不要先建数据库 / 目录？ | **不用**。首次启动自己建 `data\`，并把人格种子文件写进去。 |

## 三、要你自己准备的只有一件：模型密钥

后端要能调模型才会"活"。两种填法，任选一种：

* **界面里填（推荐）**：打开界面 → `设置` → 模型那一段，填 Base URL、模型名、API Key，保存。
  密钥落在 `data\.keys.json`，**不会**进 `config.json`。
* **环境变量**：启动前设 `IRMIA_API_KEY`（配置里 `apiKeyEnv` 指的就是这个名字）。

不填也能启动：后端会跑、界面能开，日志里会记"模型调用失败"。但不会有真正的对话。

## 四、数据落在哪（重要）

**所有运行期数据都在包内 `<包目录>\data\` 下**，不往系统盘别处写：

| 路径 | 是什么 |
| --- | --- |
| `data\events\*.jsonl` | **事件日志（唯一真相源）**：发生过的一切，一行一条，只增不改 |
| `data\persona\` `data\MEMORIES\` | 人格资产与记忆（她的人设、世界事实、关系） |
| `data\.versions\` | 人格/工作区文件的逐版本快照（可回滚） |
| `data\.auth.json` | 进界面的密码凭据（**别外发**；忘了密码就删掉它重启，回到"再设一次"） |
| `data\logs\backend-*.log` | 每次启动的 stdout / stderr |
| `data\workspace\` | 她干活的工作根（下载、写文件都在这） |
| `config.json` | 配置（在包根，不在 data 下） |

* **恢复出厂**：关掉程序，删掉 `data\` 整个目录（想连配置一起重置就顺手把 `config.json` 也删掉，
  下次启动会自动从 `config.example.json` 复制一份新的）。
* 程序**崩溃或被强杀都不丢数据**：事件日志是唯一真相源，下次启动会自动恢复没结算完的那一步。

## 五、几个常见情况

* **端口 7788 被占用**（启动器会直接告诉你）：把 `config.json` 里 `"port": 7788` 改成别的值
  （例如 `7801`）保存，重新双击 `START.cmd`。界面端口跟着配置走，不用改别的地方。
* **重启**（界面 `运行情况` 页右上角那颗按钮，或托盘菜单）：包里**带着 `restart.ps1`**（在**包根**，
  不在别处）——它按"安装根"认出后端进程、停掉它、**等它真的退出**再拉起新的，并把
  `[回执]` / `[实例]` / `[结束]` 三行写进 `data\restart-trace.log`（出问题时把这份日志一起发来）。
  手动重启也行：在包根跑 `pwsh -File restart.ps1`（想看它打算做什么而不真动手：加 `-DryRun`）。
* **关界面 ≠ 关掉她**：点窗口右上角的「叉」= **退出界面**，但后端照常在跑（她本来就该一直在线），
  想再看就重新双击 `START.cmd`。想让「叉」改成"收进托盘"，在界面 `设置` 里打开
  「关窗时收进托盘（不退出界面）」——那之后右键任务栏托盘区的 IRMIA 图标 → **退出** 才退出界面。
  要连后端一起收工：回到那个黑窗口按 `Ctrl+C`，它会打印「界面已关，正在停后端…」并自己收尾。
* **关掉黑窗口**（直接叉掉启动器那个 cmd 窗口）：后端可能留在后台继续跑。这不算故障——下次双击
  `START.cmd` 会认出它并复用（会打印"后端已在运行——复用它"），要停它就在任务管理器里结束那个
  `node.exe`，或者下次启动后正常退出一次。
* **想让后端在关掉界面后继续无人值守地跑**：命令行里执行 `START.cmd -KeepRunning`。
* **不想每次手动启动**：这一版没做开机自启，属于已知缺口（见第八节）。

## 六、怎么反馈问题（最有用的三样）

1. **版号**：界面 `设置` → `关于` → `版本`，应当显示 `v@@VERSION@@`。
2. **日志**：`data\logs\` 下最新那份 `backend-*.out.log`（以及 `.err.log`，如果非空）。
3. **现场**：出问题那一刻的截图 + 你当时在做什么（点了哪个页面、发了什么消息）。

如果怀疑是数据/状态问题，再附上 `data\events\` 里最近那个 `.jsonl` 的**最后 200 行**就够定位了。
⚠️ 发之前把 `data\.auth.json` 与 `data\.keys.json` 删掉或打码——前者是进界面的凭据，后者是你的密钥。

## 七、卸载

1. 退出界面：点窗口的叉（或在设置页打开过「关窗时收进托盘」时，右键托盘区的 IRMIA 图标 → **退出**）。
2. 关掉那个黑色启动窗口（后端会由启动器一起停掉）。
3. 删掉整个包目录。
4. （可选）删掉 `%APPDATA%\Irmia\`：里面只有界面自己的东西（`ui-state.json`，以及 `sessions\` 下每个实例一份的登录凭据）。

## 八、内测须知（已知限制，别当 bug 报）

* **没有安装器**：这一版是 zip 便携包。开始菜单入口、安装目录选择、卸载项都还没有。
* **外部依赖不随包分发**：`pwsh 7` / `ripgrep` / `es.exe` 要另装（ripgrep 与 es 可以在界面
  `设置` → `外部依赖` 里一键装；pwsh 7 请用 `winget install Microsoft.PowerShell` 自己装）。
  没装不影响启动，只是相关工具用不了。
* **消息通道出厂关闭**：`config.json` 里 `channels.qqOfficial` 与 `channels.onebot` 都是 `false`，
  要用 QQ 得自己在界面里配（这一版不预置任何账号）。
* **没有代码签名**：`node.exe` / `irmia_gui.exe` 都未签名，杀毒软件或 SmartScreen 可能拦一下
  （选"仍要运行"即可；若文件被直接删掉，把包目录加白名单后重新解压）。
* **是 beta**：升级包可能不兼容旧 `data\`，破坏性改动会写在发布说明里。
